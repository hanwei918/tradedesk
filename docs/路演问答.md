# 路演与摊位问答

每题 20 秒内答完。数字都能在仓库里查到出处；查不到的不要说。

| 问题 | 答法 |
|---|---|
| GitHub 上随便抄个 skill 就能做多平台上架，你们的亮点在哪？ | 对，生成谁都能做，我们不跟它抢。亮点是发出前那道关：skill 写出来的 "UL Listed" 你敢发吗？贴进“文案体检”，几秒告诉你哪句不能发、依据是哪条规则或哪个资料字段；模型编的规则编号，代码直接拦下（红队 5/5）。说完当场贴一段演示 |
| 你们是 toB 还是 toC？ | 用户是工厂，toB 工具。询盘回复对 B 端进口商，上架对 C 端消费者，同一张资料卡、同一套合规检查 |
| 和 Accio / 平台自带的 AI 有什么区别？ | 我们不替代写作，做发出前的合规校验层：用工厂自己的资料卡，每条提示都有规则出处，没出处的被代码丢掉。别的工具写的文案也能贴进“文案体检”查。（我们没逐项核实过 Accio 的功能，不评价它） |
| 为什么不直接用 ChatGPT？ | 对照实验里，通用 AI 只看询盘，8 条回复全部带红色问题。手动把工厂资料贴进去，红色就清零了，所以差距主要来自资料。我们的作用是每次自动带上资料、给每条提示挂出处、标红黄绿、派任务、接着生成上架文案，不靠业务员记得贴 |
| 准确率多少？ | 两份盲测集，出题人没看过代码：第一份首次精确率 97.1%，第二份 92.3%，召回率 94.4% 和 82.8%。只说首次成绩。也有抓不到的，比如不带 MOQ 关键词的起订量承诺，评测页写明了 |
| 成本多少？ | 每条询盘的模型费约 0.24 美元（约 1.7 元，回复加改一轮，5 次调用），这是模型成本，不是省下的钱；每个产品的上架文案约 0.14 美元。这是录制时的真实 token 用量乘 claude-opus-5-5 官方价算的；现场走 Tokenhub 的 gpt-5.5，价格以 Tokenhub 计费为准 |
| 有真实客户吗？ | 还没有，演示用的工厂、产品、询盘都是虚构的。下一步是找宁波工厂，用真实询盘试用 |
| 规则过期怎么办？ | 每条规则带原文链接和抓取日期（10-26、10-31）。知识库页有“重新抓取出处”：10-31 程序重新抓了 61 条，24 条原文仍在；35 条是靠脚本显示的页面或 PDF，程序看不到正文（建档时已在浏览器或用 pdftotext 逐字核对）；2 条网站拒绝程序；0 条没找到。还没有定时自动监控 |
| 规则从哪来？ | 平台帮助中心和各国官方法规页面，每条附原文和链接。阿里平台规则取自阿里国际站规则中心 |
| 数据安全吗？ | 程序在本机运行，key 只存本机、不进仓库。询盘内容会发给模型服务商处理，现场是 Tokenhub。演示数据全部虚构，没爬付费数据 |
| 会不会自动发给买家？ | 不会。红色和黄色提示必须有人看过，系统不自动发送 |
| 换一家工厂要多久？ | 同品类只换资料卡。换品类也验证过：10-31 加了第二家示例工厂（宁海杯壶的 500ml 保温杯），写一张资料卡、加一个认证名的识别，上架、文案体检、询盘回复直接跑通，原来那家工厂的请求一字不变。加平台要写规则、提示词，并在代码里登记 |
| 能上哪些平台？都查平台规则吗？ | 上架可选 11 个平台，每个平台单独选输出语言。Amazon 美英德日站、Walmart、eBay、Etsy、Mercado Libre、AliExpress 都有核实过的平台规则，还会用上所在市场的合规规则（比如 Walmart 查美国、Mercado Libre 查墨西哥 NOM）。Shopify 独立站没有官方文案规则，只核对工厂资料卡 |
| 工厂的水壶能上 Etsy 吗？ | 不一定。Etsy 不允许转售市面上可买到的商品，系统会提示人工确认，不会替你写成手工制作 |
| 为什么不做 AI 生成主图？ | Amazon 要求主图是实拍，生成的图本身就违规 |
| 和现有做法比，你们站在哪？ | 看 PPT 定位对比页。通用 AI 不带工厂资料，8 条回复 8 条带红；贴上资料红色清零，仍有 20 处待确认；我们自动带资料、改一轮后 3 条可直接发、8 处待确认，每条提示挂出处。平台自带工具各家不同，我们没逐个测，不下结论 |
| 现场是真调用还是录好的？ | 摊位默认用回放（录好的真实调用，一秒出结果）。要证明新输入也能跑：开“开摊自检”页 → “实时验证”，随机生成一条没录过的询盘，实时调用 3 次、约 20 秒，结果和耗时留记录、写进调用日志 |
| 省多少人工有证据吗？ | 还没有工厂试用数据。现场可以计时：“评测与对照 → 降本测算 → 现场实测”，一次手写回复、一次用 TradeDesk，测到的数标 n，可一键替换假设；没测的不写 |
| 能接真实数据吗？ | 收件箱能导入 CSV：任何能另存成 CSV 的询盘列表，有一列询盘内容就行，产品列可写编号或产品名，重复的自动跳过。导入的是新内容，要在实时模式下整理和回复。还没接阿里的接口 |
| 智能体怎么配置的？ | “智能体配置”页：6 个智能体、11 个上架平台角色，每个的职责、输入、输出、护栏、提示词全文都能看；哪步是模型、哪步是代码按工作流列出来。和导出的 `app/config/agents.json` 是同一份，有测试保证两边一致 |
| 回复和上架文案会不会说法打架？ | 回完询盘点“为这个产品生成上架文案”，上架页顶部逐项核对回复和 Listing：没有的认证有没有被写成有、没检测的材料宣称、容量、电压。纯代码核对，不经过模型 |
| 询盘没成交，前面花的成本不就白费了？ | 对，所以先排优先级：收件箱按公开公式给每条询盘打分，每一分挂询盘原文，业务员先回值得跟的；分低的（比如那条 50 分的美国询盘）先看硬冲突再决定怎么回。回复一次把做不到的事说清楚，少来回几轮，也不埋纠纷。我们没有成交率数据，不要报数字 |
| 商家要大量上品（有的平台上新到一定数量给流量扶持），你们帮得上吗？ | 商品看板就是为这个：批量生成全部产品的 Amazon 和 TikTok 文案，每格按状态（不能发 / 需人工确认 / 可上架 / 已上架）一眼看出卡在哪，导出 CSV 批量上传；“新增商品”可以当场加一个新品。具体哪个平台、多少件给扶持我们没核实，不要报门槛 |
| 你们管定价吗？ | 不做定价策略：价格是工厂自己定的，写在资料卡的 FOB 阶梯价里。我们管的是报价守底线：回复里报的价低于价目表最低一档，代码直接标红（“低于底价需要老板审批”）；数量低于 MOQ 也标红；买家的目标价低于底价时，回复如实说做不到。比如保温杯询盘买家要 3.20 美元，底价 3.80，回复按 2000 个报 4.10。参考竞品、汇率、利润率给定价建议不在我们范围，可以作为下一步 |
| 能加自己的商品吗？ | 能。商品看板“新增商品”，填资料卡（认证有哪些没哪些、MOQ、价格阶梯、规格、卖点），也可以从现有商品复制一份改；保存后上架、体检、询盘都能选它，主图在看板格子里上传。新商品没有录好的结果，生成和看图审核要在实时模式下（每步 20 秒左右） |
| 怎么收费？ | 还没验证。设想是按工厂或账号订阅，先用试用验证省下的时间值不值这个价。（说“设想”，不要报价格） |

## 计时

3 分钟讲 12 页（仓库里的 PDF 加了定位对比页，是 13 页），平均每页 15 秒，PPT 备注里每页都标了时间段。排练一次；超时就先压第 4 页（合规内核）和第 9 页（平台配置），这两页技术评委在摊位上会细看。
