# 路演与摊位问答

每题 20 秒内答完。数字都能在仓库里查到出处；查不到的不要说。

| 问题 | 答法 |
|---|---|
| 你们是 toB 还是 toC？ | 用户是工厂，toB 工具。询盘回复对 B 端进口商，上架对 C 端消费者，同一张资料卡、同一套合规检查 |
| 和 Accio / 平台自带的 AI 有什么区别？ | 我们不替代写作，做发出前的合规校验层：用工厂自己的资料卡，每条提示都有规则出处，没出处的被代码丢掉。别的工具写的文案也能贴进“文案体检”查。（我们没逐项核实过 Accio 的功能，不评价它） |
| 为什么不直接用 ChatGPT？ | 对照实验里，通用 AI 只看询盘，8 条回复全部带红色问题。手动把工厂资料贴进去，红色就清零了，所以差距主要来自资料。我们的作用是每次自动带上资料、给每条提示挂出处、标红黄绿、派任务、接着生成上架文案，不靠业务员记得贴 |
| 准确率多少？ | 两份盲测集，出题人没看过代码，首次精确率 97.1% 和 92.3%，召回率 94.4% 和 82.8%。只说首次成绩。也有抓不到的，比如不带 MOQ 关键词的起订量承诺，评测页写明了 |
| 成本多少？ | 每条询盘约 0.24 美元（回复加改一轮，5 次调用），每个产品的上架文案约 0.14 美元。这是录制时的真实 token 用量乘 claude-opus-5-5 官方价算的；现场走 Tokenhub 的 gpt-5.5，价格以 Tokenhub 计费为准 |
| 有真实客户吗？ | 还没有，演示用的工厂、产品、询盘都是虚构的。下一步是找宁波工厂，用真实询盘试用 |
| 规则过期怎么办？ | 每条规则带原文链接和抓取日期（10-26、10-31）。现在靠人工核实更新，还没有自动监控 |
| 规则从哪来？ | 平台帮助中心和各国官方法规页面，每条附原文和链接。阿里平台规则取自阿里国际站规则中心 |
| 数据安全吗？ | 程序在本机运行，key 只存本机、不进仓库。询盘内容会发给模型服务商处理，现场是 Tokenhub。演示数据全部虚构，没爬付费数据 |
| 会不会自动发给买家？ | 不会。红色和黄色提示必须有人看过，系统不自动发送 |
| 换一家工厂要多久？ | 同品类只换资料卡，代码不用改。换品类要补认证规则，再改提示词里的一句角色设定。加平台要写规则、提示词，并在代码里登记 |
| 能上哪些平台？都查平台规则吗？ | 上架可选 11 个平台，每个平台单独选输出语言。Amazon 美英德日站、Walmart、eBay、Etsy、Mercado Libre、AliExpress 都有核实过的平台规则，还会用上所在市场的合规规则（比如 Walmart 查美国、Mercado Libre 查墨西哥 NOM）。Shopify 独立站没有官方文案规则，只核对工厂资料卡 |
| 工厂的水壶能上 Etsy 吗？ | 不一定。Etsy 不允许转售市面上可买到的商品，系统会提示人工确认，不会替你写成手工制作 |
| 为什么不做 AI 生成主图？ | Amazon 要求主图是实拍，生成的图本身就违规 |
| 怎么收费？ | 还没验证。设想是按工厂或账号订阅，先用试用验证省下的时间值不值这个价。（说“设想”，不要报价格） |

## 计时

3 分钟讲 12 页，平均每页 15 秒，PPT 备注里每页都标了时间段。排练一次；超时就先压第 4 页（合规内核）和第 9 页（平台配置），这两页技术评委在摊位上会细看。
