# 队友部署说明（现场电脑）

## 1. 准备

- 一台 Mac 或 Windows 笔记本。
- **Python 3.9 或更高版本**：
  - Mac 打开"终端"，输入 `python3 --version` 检查。没有的话，从 https://www.python.org/downloads/ 下载安装。
  - Windows 从同一个网址安装，安装时**勾选 "Add python.exe to PATH"**。
- 拿到部署包 `TradeDesk-部署包.zip`，解压到桌面。

部署包里**没有任何 API key**，默认是回放模式：不联网、不花钱，演示内容是赛前用真实模型录好的结果。

## 2. 启动

| 系统 | 做法 |
|---|---|
| Mac | 双击 `start-mac.command`。如果提示"无法打开"，就右键 → 打开 → 再点"打开"。也可以在终端里运行 `bash start-mac.command` |
| Windows | 双击 `start-windows.bat` |

第一次启动会做两件事：
- 安装 Pillow，主图的像素检查要用到它，这一步需要联网。
- 用回放缓存准备好看板、收件箱和任务的数据。

完成后浏览器会自动打开 http://127.0.0.1:8765 。

- 停止服务：在黑色窗口里按 Ctrl+C。
- 再次启动：重新双击，第二次很快。
- 想把演示数据恢复到初始状态：删掉 `app/state` 文件夹，然后重新双击。

## 3. 游园会找茬（手机扫码）

1. 电脑和观众手机连同一个 Wi-Fi。
2. 加上 `--lan` 启动：
   - Mac：在终端里运行 `bash start-mac.command --lan`。
   - Windows：在命令提示符里运行 `start-windows.bat --lan`。
3. 大屏打开 http://127.0.0.1:8765/play#screen ，会显示二维码和排行榜。
4. 手机只能打开找茬页面，其他功能对手机一律返回 403。
5. 想清空排行榜，删掉 `app/state/scores.json`。

## 4. 现场换成赛事的官方模型（建议做，"能跑才算数"）

回放模式只适合断网时兜底。评委要看真实运行，所以现场最好改成实时调用：

1. **注册**（10-30 开放）：打开 https://api.tokenhubcloud.net/register ，只能用 @qq.com、@gmail.com、@126.com、@163.com、@outlook.com 邮箱，不能用手机号，不需要邀请码。注册完马上把密码记下来，网站不能自助重置密码。
2. **创建 key**：登录后左侧点「API 密钥」→「创建密钥」，创建后**立刻复制**，完整的 key 通常只显示这一次。左侧「用量」页能看余额；余额是 0 就拿注册邮箱找现场技术组。
3. 在网页左下角**点模型卡片**（写着"点击设置模型和 key"），打开"模型设置"：
   - 接口类型先选 **Claude（官方或 Tokenhub）**，接口地址改成 `https://api.tokenhubcloud.net`（**不带 /v1**），粘贴 key，点**查可用模型**。
   - 列表里有 Claude 模型（名字以 `claude` 开头）：就留在这条路，选它。名字正好是 `claude-opus-5-5` 最好，这和录制演示用的是同一个模型，第 4 步也不用重录。
   - 列表里没有 Claude 模型，或者测试连接失败：换成 **OpenAI 兼容（赛事 Tokenhub）**，地址用默认的 `https://api.tokenhubcloud.net/v1`，**重新粘贴一次 key**（换接口类型后旧 key 不会带过去），再点查可用模型，从列表里选一个。
   - 模式先选 **实时 + 录制缓存**，点**保存**，再点**测试连接**，看到"连接正常"才算好。
   - 测试失败时，提示会说明是地址写错、key 不对、这个 key 没有该模型的权限，还是额度不足。
4. 只有在第 3 步换了模型时，才需要在 `app` 目录里运行 `python3 tools/record_demo.py`（Windows 用 `python`），用新模型把演示内容重录一遍。大约 70 多次调用，几分钟，用的是赛事额度。用的还是 `claude-opus-5-5` 的话，录过的内容会直接命中缓存，不用重录。
5. 回到"模型设置"，把模式改成 **实时调用**，保存。之后每次点击都是实时调用。
6. 万一网络出问题，把模式改成 **回放（不联网）**，回放的就是第 4 步录的内容。

key 只保存在这台电脑的 `app/.env` 里，保存后页面只显示末 4 位。换接口地址时必须重新填写 key，旧 key 不会被发往新地址。手机通过局域网访问时，打不开这个设置。

注意：
- 主图检查需要能看图的模型。如果官方模型不支持图片，主图只会做像素检查，页面会提示"模型审核没有运行"。
- **不要通过微信或群聊发送 key，也不要截图、写进 PPT**。Tokenhub 的 key 等于账户里的额度。在自己电脑上填进 `app/.env`，这个文件不会被提交。
- 经 Tokenhub 调用 Claude 这条路，赛前只用本地模拟接口测过，没有用真实 key 跑过；第一次用时以"测试连接"的结果为准。

## 5. 常见问题

| 现象 | 处理 |
|---|---|
| 双击后窗口一闪就关 | Mac 改在终端运行 `bash start-mac.command`；Windows 在命令提示符里运行 `start-windows.bat`，看报错 |
| 提示没有找到 python | 按第 1 步安装 Python；Windows 安装时要勾选 Add to PATH |
| 安装 Pillow 失败（Mac 提示 externally-managed） | 不影响其他功能，只是主图的像素检查不运行；可以运行 `python3 -m pip install --user --break-system-packages pillow` |
| 页面报"没有这条请求的缓存" | 回放模式下只能点录制过的内容：用示例询盘卡片和"按风险提示全部修改"这个快捷建议，不要手动改文字 |
| 8765 端口被占用 | 已经有一个服务在跑：关掉另一个黑色窗口，或者加 `--port 8766` 启动 |
| 现场来不及手动操作 | 点网页右上角"自动演示"，12 步带字幕自动走完，按 Esc 退出；摊位循环播放打开 http://127.0.0.1:8765/#tour=loop |
