# 游园会摊位讲解稿

游园会占总成绩 **70%**，技术、行业、投资三类评委各拿一张表，在摊位前打分（选手手册「五、评审说明」）。队友 10-31 在现场打听到，我们赛道是一位行业评委、一位投资评委，以现场为准。
下面按评委类型写好了每个评分项**点哪里、说什么**。括号里是评分表编号和分值。
3 分钟路演只给晋级的队伍，占 30%；晋级名额手册写每赛道前 3，队友听到的是前 6，以现场通知为准。讲稿见 [路演稿.md](路演稿.md)，问答准备见 [路演问答.md](路演问答.md)。

进入后左边只留这个角色用得到的页面，顶部有步骤条，点“下一步”就执行真实操作，点任意一步可以跳回去。

| 角色 | 给谁看 | 路径 | 产出 |
|---|---|---|---|
| 商户 | 行业评委、投资评委 | 收件箱排好优先级（高亮那条 50 分的美国询盘：硬冲突多，分低是提醒要小心回）→ 理解并回复这条询盘 → 一句中文改第 2 轮 → 看这条询盘派出去的任务 → 附上 Amazon 美国站文案（Mark 在 Amazon 卖货；顶部表格由代码逐项核对回复和 Listing 有没有说法打架） | 能直接发给进口商的回复、中文备忘、跨岗位任务、附给买家的 Amazon 文案 |
| 合规审查员 | 技术评委、关心合规的评委 | 检查一段待发文案 → 每条问题都有出处 → 61 条规则逐条核实（顶部有出处自检结果）→ 编造的提示拦得住吗 → 6 个智能体怎么分工（智能体配置页） | 红黄绿结论，每条问题附规则原文和链接 |
| 消费者 | 关心 B2C 和本地化的评委 | 美国和墨西哥的商品页 → 换到德国和墨西哥电商 → 页面上不会出现的话（这条线只显示买家看得到的部分，顶部写明资料卡里没有的认证） | 按平台和语言生成、只写真实认证的商品页 |

三条线在回放模式下都已整条跑通；消费者线用到的 Amazon 德国站、Mercado Libre 是 10-31 晚用 gpt-5.5 录的。每条线走完会出现“下一条线”按钮，三条线可以连着走；也可以点“换个角色”，或在选角色页点“进入完整工作台”看全部功能。角色模式下数字快捷键不起作用，避免评委误跳到别的页面。

## 开场 30 秒（谁来都先讲这段）

> 做外贸，合规是守住利润的底线：从开发客户到收回货款，任何一个环节疏忽，都可能货物被扣、罚款，甚至钱货两空。
> 我们做的是 TradeDesk，给宁波中小外贸工厂的业务员和运营用。
> 用户是工厂。询盘回复是对 B 端进口商的，多平台上架是对 C 端消费者的，看板是运营内部用的。两条销售线用同一张资料卡、过同一套合规检查。
> 一条询盘进来，它先找出买家要求和工厂资料对不上的地方，再用买家的语言写回复，同时按平台规则检查；同一个产品接着就能生成 Amazon 和 TikTok 的上架文案。
> 每一条风险提示都挂着出处：公开规则的原文和链接，或者工厂资料卡上的那个字段。说不出出处的，代码直接丢掉。

然后问一句：“您更关心技术实现、业务场景，还是投入产出？”按下面对应的部分讲。

## 演示只走一条主线（应对“不堆功能”）

**主线，约 2 分钟，谁来都走这条：**

1. 概览：5 秒，只说“这是工厂每天打开的第一屏”。
2. 询盘收件箱：点美国询盘 INQ-US-01，然后点“处理”。
3. 询盘回复第 1 轮：指右边风险面板，点开一条提示，看规则原文和链接。
4. 在底部输入框打“按风险提示全部修改”，进入第 2 轮。
5. 点“为这个产品生成上架文案”，进入多平台上架，看 Amazon 和 TikTok 手机预览。顺口说一句“这是 B2C 那条线”。
6. 点“去商品看板”，看这个产品在各渠道的状态。

**评委问到才打开：**

| 评委问 | 打开 |
|---|---|
| 能省多少钱 | 评测与对照 → 降本测算（请评委改成他知道的数） |
| 准不准 / 会不会编 | 评测与对照 → 规则评测、红队测试 |
| 别的国家呢 | 收件箱里的德国、日本、哈萨克斯坦、尼日利亚询盘 |
| 是真调用还是录好的 | 调用日志页，或当场实时跑一条美国询盘 |
| 路过的观众 | 游园会找茬（扫码答题） |

实时模式跑一条美国询盘约 20 多秒。日语询盘实时跑很慢，以前超时过，现场不要实时跑日语。网络不稳就用回放模式启动。

## 不要说的话

- 不要说“能省 X 小时 / X 元”而不说明是假设。实测的只有模型费用和耗时。
- 不要说用的是 Claude：现场走赛事 Tokenhub，用的是 gpt-5.5；仓库里的回放缓存和对照实验才是赛前用 claude-opus-5-5 录的。
- 不要说盲测满分：对外只说首次成绩（精确率 97.1% / 92.3%，召回率 94.4% / 82.8%）。
- 被问到做不到的事就直接说做不到，比如不带 MOQ 关键词的起订量承诺，代码规则抓不到（评测页写明了）。
- 不要说整个产品是 toC。用户是工厂；询盘是 B2B，上架是 B2C。
- 不要说 Accio 或其他平台工具做不到什么，我们没核实过。
- 不要说有客户或有工厂在用。
- 不要把现场测的 1 次人工用时说成平均值，也不要据此报“省 X%”。
- 不要报“多少工厂两条线都做”的比例，我们没有数据。
- 不要说用了 onetouch.alibaba.com 的数据，主办方说过它不是数据源，我们也没用。
- 不要说规则“全部自动核实”：出处自检里 35 条程序看不到正文，靠的是建档时的人工核对。
